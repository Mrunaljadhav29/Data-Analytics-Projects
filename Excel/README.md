# Excel Pivot Table Dashboard

## Project Overview

An interactive Excel Sales Dashboard created to analyze sales performance and present key business insights using PivotTables, PivotCharts, Slicers, and Timelines.

## Business Analysis

The dashboard provides analysis of:

- Total Revenue
- Total Orders
- Total Quantity Sold
- Average Order Value
- Monthly Revenue Trend
- Revenue by Region
- Revenue by Product Category
- Revenue by Sales Channel
- Top 5 Products by Revenue

## Excel Skills Used

- Excel Tables
- PivotTables
- PivotCharts
- Slicers
- Timeline
- Sorting and Filtering
- KPI Analysis
- Sales Analysis
- Dashboard Design
- Data Visualization

## Dashboard Features

- Interactive filtering using Slicers
- Date filtering using Timeline
- KPI cards for key metrics
- Monthly sales trend analysis
- Regional performance comparison
- Product category analysis
- Sales channel contribution
- Top product analysis
